Global explanations describe which features influence payment-risk predictions across the dataset. Local explanations describe how individual features contribute to one person's predicted risk. Global importance does not mean that the same feature dominates every prediction.

SHAP values explain model outputs relative to a background reference. Their units depend on the explainer configuration: they may represent raw model scores, log-odds, or probability differences. The actual output unit and background dataset must be verified before interpreting the values.
